# Third-party and shared materials

The combined plugin is distributed under GPL-3.0-or-later; see [LICENSE](LICENSE). Corresponding source is available in this repository and `3dtabletop-source.zip` generated by the build tooling.

Original notices and exact source provenance are retained under [`src/main/resources/META-INF/`](src/main/resources/META-INF/):

- NucleoidMC/Gomoku — MIT.
- jwang541/Xiangqi — MIT.
- hongsenliu/chinese-checkers — GPL-3.0-or-later.
- bhlangonijr/chesslib — Apache-2.0.
- Gson — Apache-2.0 runtime libraries included in the shaded JAR.

`ui/MessageText.java` and `ui/LabelLayout.java` are adapted from GoldenEggOVO/3DCasinoGames, revision `a4ddd20`, under its GPL-3.0 license. Tabletop's label fitting retains all status lines. These are bundled source utilities; installing Casino is not required.

Paper/Adventure and JOML are supplied by the server API. Private fonts, runtime configuration, worlds and third-party server/plugin JARs are not distributed here.

The bundled chesslib subset omits unused event observers, deprecated FEN aliases and Polyglot opening-book hashing. Standard move validation and repetition detection remain in use. The original Apache-2.0 notices and source provenance are retained. Embedded sources live under `rules/chess/engine/`, `rules/xiangqi/engine/` and `rules/chinesecheckers/engine/`.

The 1.7.0 Last Card, Mahjong, dice animation and hand models are independently implemented in this repository. Public rules and factual option names informed the behavior; Nintendo or other game artwork was not copied. The user-supplied MahjongCraft binary was inspected only for its configuration and public yaku names, not copied or used as a runtime/build dependency. No code or assets from that binary are distributed. See [game references](docs/game-modes.md) and [regional house rules](docs/mahjong.md) for sources and deliberate differences.

The 1.7.1 card and Mahjong face patterns are original pixel drawings converted into native Display geometry. The user-supplied BoardGames-1.1 binary was inspected only for its archive structure and public rendering signatures (SVG and Display usage). None of its code, SVG files or other assets were copied or included; it is not a dependency.

The optional resource pack uses transparent tile artwork from [lietxia/mahjong_graphic](https://github.com/lietxia/mahjong_graphic), revision `3e275804ff58325306710bef3a7406860444bc6a`, under its M+ fonts license permitting modification and commercial use. Selected PNGs and their SVG sources are retained under `resource-pack/source/mahjong/tiles/`; the full notice and file hashes are centralized in `resource-pack/sources.json`, and the generated pack includes the notice. The former Mahjong Soul tile atlas and project-generated flower substitutes have been removed.

One Mahjong Soul tablecloth and nine short sound effects remain from the user-specified [public archive](https://files.riichi.moe/mjg/game%20resources%20and%20tools/Mahjong%20Soul/game%20files/). Exact URLs and original SHA-256 digests are recorded in `resource-pack/sources.json`. No license grant is inferred from public availability; these third-party assets are separate from the plugin's GPL code and are included for the requested local acceptance build, with no public Release published. Color Eight artwork and model geometry are created by this project. CraftEngine is optional and its binary is not redistributed.

The resource-pack Xiangqi faces use the user-selected traditional-character SVGs from Wikimedia Commons (Inductiveload, with current vector revisions by Wj654cj86), released into the public domain. The first red and third black piece are selected from each SVG. Original SVGs and locally rendered PNGs are retained under `resource-pack/source/xiangqi/`; exact hashes and file page links are in `resource-pack/sources.json`. Resource-pack poker faces and the blue reverse use [Pixel Playing Cards Pack by George Blackwell](https://georgeblackwell.itch.io/playing-cards-sprite-pack), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The original 60x84 PNGs are retained under `resource-pack/source/playing-cards/`. Faces receive three pixels of vertical padding and nearest-neighbor 2x enlargement; only the large joker corner lettering is recolored red. Author credit, license links and these changes are recorded in `resource-pack/sources.json` and in the generated pack notice. Native head catalogues and their source images are unchanged. These resource-pack updates add no model elements or runtime entities.

The former Doudizhu and Liar's Bar recordings have been removed from the source and generated pack. Shared card play uses the user-provided `oxidvideos-taking-playing-card-522520.mp3` recording; its original download page and license receipt were not supplied. Additional gameplay and menu effects use Kenney CC0 samples. Audio files are grouped by purpose under `audio-source/`; `audio-source/events.json` maps shared events to samples. Source links, original file hashes and license notices are centralized in `resource-pack/sources.json`, including the supplied card recording's provenance. The builder retains the Kenney notices in the generated pack.

The 1.10.6 local acceptance build uses cropped zombie, skeleton and creeper head textures from the user's Minecraft 26.2 client JAR (`assets/minecraft/textures/entity/`). The card layout, suits and Wither sprite are project artwork. Minecraft textures remain Mojang/Microsoft assets, separate from GPL plugin code. Only head-front pixels were imported into offline PNG sources; signed skin properties are embedded for native rendering. The API key and generation cache are excluded. No public Release has been published for this build.
