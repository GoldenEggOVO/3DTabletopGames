# 1.7.3-SNAPSHOT 客户端验收单

本版未发布 Release，本次未部署正式服。下列未勾选项目保留为 Minecraft 客户端验收项；本地图案与模型预览不代表实机通过。

## 本批新增：麻将布局与视角

- [ ] 麻将瞄准一张牌时亮边框并抬起，邻牌不动；移开、切换目标和重启后还原且无残留高亮。17 张手牌为单排，四个座位均无相邻手牌重叠。
- [ ] 可吃／碰／杠／和时，本人手牌上方按钮清楚可点，对手与观众看不到；规则不允许的操作或跳过不会出现。
- [ ] 吃／碰／杠显示完整立牌组合，多种组合可在桌上展开、返回和选取；立直出牌仍可选择。响应后按钮及时消失，不可重复提交旧动作。
- [ ] 自己回合跳过仅收起提示，仍可正常出牌；响应别人时跳过按当前地区规则推进。离开视距再回来可重新显示尚合法的提示。
- [ ] UNO 中央弧形箭头可见并平滑转动，Reverse 后方向翻转；暂停、结束与悔棋协商时静止。
- [ ] 数字6中央及角标下划线清楚，9渲染示例同样有线；卡牌悬停、邻牌让位和牌堆摸牌保持可用。当前牌库仍为1–8。
- [ ] 修改 `table.mahjong.*` 语言键后，按钮使用自定义标签，长标签不溢出底板。

- [ ] 选中普通牌显示未见张数：本人 2／公开 0 显示 2，本人 1／公开 1 也显示 2；赤五同类合算，公开牌不重复计算；对手与观众看不到本人提示。
- [ ] 中央四向余牌数与牌墙同步，桌上方显示局数、当前回合、真实剩余秒数和最近弃牌人／牌；暂停、悔棋、结束状态不继续假倒计时。
- [ ] 四个座位按住 Shift 都能固定在各自高位观察并转动鼠标；松开恢复之前的位置和朝向，可正常选牌／点击操作，不误开菜单。
- [ ] Shift 中打开菜单、离桌、断线、死亡、撤销权限、外部传送和关闭插件后没有残留固定视角／关闭重力；返回点被堵或传送被其他插件取消时不强行传送。检查反作弊兼容。
- [ ] 日麻立直出现红点白棒，下一副清理，场上供托数正确；重启恢复仍匹配保存的对局。

## 既有：牌面、手牌交互与菜单

- [ ] 客户端不加载资源包，Last Card 仍显示原创彩色牌面；麻将显示可辨认的花色与字牌图案，移动视线时无明显闪烁、镜像或反向。
- [ ] Last Card 手牌放大竖立，在两人、三人和四人桌分别从自己的正常站位检查朝向与可读性；多排手牌仍可选中。
- [ ] Last Card 瞄准手牌时只有该牌抬高，邻牌稍微让位；移开后恢复。瞄准抬起牌的可见部分仍能选中它，其他玩家看不到这些私有变化。
- [ ] 从默认站位瞄准中央牌堆并右键：仅允许摸牌时执行；有可出牌且无罚摸、非本人回合等不允许状态不能摸牌。手牌上方的空白区域不会误拦牌堆点击。
- [ ] 实时摸牌时新牌从中央牌堆进入本人手中；飞行中瞄准新牌，落下后仍保留悬停抬高。重连、重新显示手牌和重启恢复不重播旧摸牌。
- [ ] 基础设置只需模式、人数及麻将地区／围棋大小；详细规则可以翻页修改，返回后保留草稿，创建按钮清楚可见。
- [ ] 等候页突出准备、房主补陪练及详情；对局页突出回桌与操作手牌／棋盘。规则、公开牌面、悔棋和退出可在房间选项找到，手牌页不重复整份规则和成员表。
- [ ] 房间返回游戏目录；房间列表返回当前房间或目录，不会意外进入创建页。
- [ ] 原样 1.7.0 默认设置、房间和手牌模板显示新布局，但磁盘内容不变；自定义模板的顺序与样式保留。手动合并新版模板前有可恢复的备份。
- [ ] 象棋双方棋面使用中文，“砲”可读；Ludo 小人没有浮动编号，叠子选择菜单仍能区分棋子；骰台没有额外矩形假影，滚动、停稳和恢复时均无残留。

## 既有设置页、投骰台、手牌桌回归

- [ ] 双人游戏选后手／随机先手时，本人站到对应座位，房主仍可开始游戏。旧菜单不能在新房间执行旧动作。

- [ ] 新骰子桌需要额外侧面空间；旧桌重启位置不动，使用紧凑投骰台。离开、关桌和重启后没有残留骰子实体。

## Ludo 与模型

- [ ] 目录和 Tab 显示 Ludo；`/3dtabletop create ludo 2` 使用对角颜色，4 人桌各自对应营地。
- [ ] 开局每人首枚小人自动出营；其他棋子等待 6 点。路线无飞行棋跳跃与回弹，终点要求精确点数。
- [ ] 骰子滚动时不接受重复操作，停止后标出可走棋子；瞄准显示目的地及捕获/终点提示。
- [ ] 单枚点击直接移动；叠子提示“选择棋子”，Dialog 可以选具体编号。
- [ ] 其他玩家看不到自己的私有提示；换回合、离桌和关闭房间后提示清理。
- [ ] 象棋棋饼、中国跳棋底座轮廓及吃子目标边框清楚，没有闪烁或遮挡。
- [ ] 旧飞行棋存档按旧规则恢复，并显示 Legacy；新 Ludo 重启后恢复同一棋盘与骰子进度。

详细规则及升级边界见 [Ludo 说明](ludo.zh-CN.md)。

## 菜单与操作

| 检查 | 操作与预期 |
| --- | --- |
| 入口与语言 | 输入 `/3dtabletop`，确认标题为 **3D Tabletop Games**、默认英文、离开确认按钮为英文；根指令 Tab 列表没有重复的命名空间候选。自定义语言与菜单应继续保留。 |
| 房间浏览 | 浏览房间、查看规则并返回；自己的房间显示 Resume。如有超过一页的同类房间，再逐页检查。 |
| 菜单落子 | 四子棋房间进入 Choose a Board Move，选择列后直接落子；菜单列号从 1 开始。原始 `/move drop:3` 指令仍表示第 4 列。 |
| 新桌菜单 | 新建后立即潜行右键打开桌子；四子棋站在两侧瞄准上半部棋架也能打开。 |
| 无效操作 | 点击五子棋已占用位置或四子棋满列，查看动作栏提示；不应连续刷聊天，也不应改变棋盘。 |
| 旧菜单 | 打开离开确认后，让原房间关闭并加入另一个房间；旧确认不能把你从新房间退出。 |

## 模型

- **四子棋**：从正反两侧观察圆形阶梯棋子；移动视线时，绿色私有落点框应跟随合法列并显示实际落点。另一名玩家不应看见你的私有预览。填满一列、完成胜局，再重开。
- **黑白棋**：翻转多个棋子，确认动画结束后的黑白面与局面一致；连续动作后不应留下旧棋子。
- **围棋**：进入数目阶段，反复标记、取消一组死子；石子位置不跳动，红色标记正确出现和消失。
- **国际象棋**：双方马头面向对手，移动后仍保留朝向；检查棋子底座和桌面是否有明显闪烁。

## 桌边与恢复

- 入座后在自己的桌边检查防推挤与饥饿保护；走到距桌心超过六格的位置，碰撞设置应在一秒内恢复。换世界和退出游戏应立即恢复原碰撞设置。
- 两名玩家分别创建桌子，尝试让新桌中心靠近已有桌子：X、Z、Y 三个方向都不足三格时应收到拒绝提示。已有存档中的近距离桌子仍应按原位置恢复。
- 玩几步后正常停服、重启，再用 `/3dtabletop resume` 返回，核对座位、棋子和对局进度。不要清空 `rooms.json`。
