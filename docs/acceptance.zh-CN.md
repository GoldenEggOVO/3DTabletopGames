# 当前客户端验收清单

此清单用于 Minecraft 客户端实测。自动测试、服务器启动、实体探针和本地模型预览不能代替画面、音效与操作手感验收；每次交付的实际验证结果单独记录，未勾选项不表示已经通过。

## 共用菜单与房间

- [ ] 潜行＋右键瞄准任一桌面区域均能打开菜单，不要求命中可互动实体；普通点击不会误开菜单或重复执行动作。
- [ ] 资源包开关文字状态与颜色正确；顶部返回游戏与浏览房间按房间状态互斥显示，游戏按钮按 1｜2、3｜4 排列，直接离开房间可用。
- [ ] 准备、机器人、观战、退出、断线重进、再来一局和重启恢复正常；旧菜单不能修改已经变化的房间。
- [ ] 中英文菜单、桌面提示与动作错误无混用；固定菜单和翻译热重载正常。

## 卡牌

- [ ] 原版扑克与 Color Eight 的 32×48 牌面清楚；扑克牌 J／Q／K 的怪物配色与 Joker 凋零图案正确。
- [ ] 白边与蓝色牌背无共面闪烁，密集手牌与桌面出牌不穿插；已选中的牌不会再次被悬停抬高。
- [ ] 指针瞄准相邻牌之间或牌下方时，不出现左右／上下反复跳动；本人私人牌面、其他玩家牌背与旁观隐私正常。
- [ ] 斗地主的地主牌位于桌心，动作按钮在手牌前方；骗子酒馆轮盘提示不遮牌，质疑与轮盘结算正常。
- [ ] 德州扑克 Raise 输入能提交合法加注；跟注、弃牌、全下、公共牌、边池与筹码显示正常。
- [ ] Color Eight 的 Pass 在手牌前方近侧平放，方向箭头、回合指示与选色按钮清楚。

## 棋盘与桌子

- [ ] 资源包棋盘与桌子轮廓匹配；四子棋、圆桌、国际象棋等模型没有非预期空隙、扇形内部贴片或闪烁。
- [ ] 原版圆桌连续桌面与 36 边木沿接合，木沿仅略高于桌面；方桌没有多余护栏，麻将与骰子操作桌的必要桌沿保留。
- [ ] 四子棋支架不遮棋盘，预选框方正，落子动画与重启位置正确。
- [ ] 国际象棋王的十字架与马无重叠闪烁；黑白棋翻面、西洋跳棋升王、围棋死子标记与其他棋类落点正常。

## 快艇骰子与 Ludo

- [ ] 快艇左桌计分、右桌操作五颗骰子；掷骰后排成一排，保留／取消仅移动对应骰子，不牵动其他骰子。
- [ ] 计分高亮与格子对齐，指针选择框可见，骰子瞄准高亮清楚；上下半区、小计、奖励和总分与实际规则一致。
- [ ] 计分桌没有木护栏或独立菜单按钮，两个桌面都能潜行＋右键打开房间菜单。
- [ ] Ludo 骰子托盘、掷骰动画、点数停稳和棋子移动正常；动画期间不重复操作。

## 麻将

- [ ] 四座牌面与舍牌朝向正确，绿色牌背可见；吃碰杠与立直横牌位置正确，暗杠不泄露私人牌面。
- [ ] 按住疾跑键（默认 Ctrl）固定看桌，松开恢复；退出、死亡、传送、断线和重启后没有镜头状态残留。
- [ ] 日麻五个宝牌槽位、开杠后的新指示牌、供托与本场计数正确；立直后自动出牌，在可以和牌时停下。
- [ ] 理、和、鸣、切位于本人前侧桌沿右半段，功能提示只解释用途，明暗状态与行为一致；和牌者的手牌全部平放。
- [ ] 四种房规的公开信息、私人动作、和牌、流局与下一局正常。

## 音效与性能

- [ ] 出牌录音与落子、掷骰、翻面、下注匹配；不同渲染模式玩家听到正确音效，关闭和音量设置有效；轮到自己时没有额外提示音。
- [ ] 未提交动作、历史回放、重启恢复和单纯重绘不重复发声。
- [ ] 分别在原版与资源包模式下测量空桌、满手牌、多桌和观战场景的客户端帧率。实体减少或服务端探针通过不代表客户端帧率已经改善。
