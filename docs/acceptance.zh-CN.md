# 1.6.1-SNAPSHOT 客户端验收单

## 本批新增：游戏音效

- [ ] 各游戏落子、移动的音量合适；附近两张桌子同时操作不会造成明显干扰。
- [ ] 吃子、黑白棋翻子、掷骰、Ludo 到家、围棋停手与计分提示可以分辨。
- [ ] 新开局、胜负或和局、完成悔棋各有短提示；没有持续音乐。
- [ ] 到你回合只向附近的你提示，旁观者和其他座位不会收到私人轮次声。
- [ ] 实体点击与菜单移动各触发一次；无效操作、刷新菜单、重启恢复不重播落子声。
- [ ] 客户端“方块”音量可以调节；服务端 `sounds.enabled: false` 或 `sounds.volume: 0` 重启后关闭所有插件音效。

音效类别、配置及验证边界见 [音效说明](sounds.zh-CN.md)。

## Ludo 与模型

- [ ] 目录和 Tab 显示 Ludo；`/3dtabletop create ludo 2` 使用对角颜色，4 人桌各自对应营地。
- [ ] 开局每人首枚小人自动出营；其他棋子等待 6 点。路线无飞行棋跳跃与回弹，终点要求精确点数。
- [ ] 骰子滚动时不接受重复操作，停止后标出可走棋子；瞄准显示目的地及捕获/终点提示。
- [ ] 单枚点击直接移动；叠子提示“选择棋子”，Dialog 可以选具体编号。
- [ ] 其他玩家看不到自己的私有提示；换回合、离桌和关闭房间后提示清理。
- [ ] 象棋棋饼、中国跳棋底座轮廓及吃子目标边框清楚，没有闪烁或遮挡。
- [ ] 旧飞行棋存档按旧规则恢复，并显示 Legacy；新 Ludo 重启后恢复同一棋盘与骰子进度。

详细规则及升级边界见 [Ludo 说明](ludo.zh-CN.md)。

先在隔离测试服安装本地 JAR；停服替换并保留原配置、语言、菜单和房间存档。自动验收结果见 [验证记录](verification.md)。下面的画面和手感项目仍需 Minecraft 客户端确认。

## 菜单与操作

| 检查 | 操作与预期 |
| --- | --- |
| 入口与语言 | 输入 `/3dtabletop`，确认标题为 **3D Tabletop Games**、默认英文、离开确认按钮为英文；根指令 Tab 列表没有重复的命名空间候选。自定义语言与菜单应继续保留。 |
| 房间浏览 | 浏览房间、查看规则并返回；自己的房间显示 Resume。如有超过八个同类房间，再逐页检查。分页已由自动探针用 25 个房间验证，单人验收无需额外准备这些房间。 |
| 菜单落子 | 四子棋房间进入 Controls，选择列后直接落子；菜单列号从 1 开始。原始 `/move drop:3` 指令仍表示第 4 列。 |
| 新桌菜单 | 新建后立即潜行右键打开桌子；四子棋站在两侧瞄准上半部棋架也能打开。 |
| 无效操作 | 点击五子棋已占用位置或四子棋满列，查看动作栏提示；不应连续刷聊天，也不应改变棋盘。 |
| 旧菜单 | 打开离开确认后，让原房间关闭并加入另一个房间；旧确认不能把你从新房间退出。 |

## 模型

- **四子棋**：从正反两侧观察圆形阶梯棋子；移动视线时，绿色私有落点框应跟随合法列并显示实际落点。另一名玩家不应看见你的私有预览。填满一列、完成胜局，再重开。
- **黑白棋**：翻转多个棋子，确认动画结束后的黑白面与局面一致；连续动作后不应留下旧棋子。
- **围棋**：进入数目阶段，反复标记、取消一组死子；石子位置不跳动，红色标记正确出现和消失。
- **国际象棋**：双方马头面向对手，移动后仍保留朝向；检查棋子底座和桌面是否有明显闪烁。

## 桌边与恢复

- 入座后在自己的桌边检查防推挤与饥饿保护；走到距桌心超过六格的位置，碰撞设置应在一秒内恢复。换世界和退出游戏应立即恢复原碰撞设置。
- 两名玩家分别创建桌子，尝试让新桌中心靠近已有桌子：X、Z、Y 三个方向都不足三格时应收到拒绝提示。已有存档中的近距离桌子仍应按原位置恢复。
- 玩几步后正常停服、重启，再用 `/3dtabletop resume` 返回，核对座位、棋子和对局进度。不要清空 `rooms.json`。

记录异常时请附上游戏类型、操作顺序、截图和客户端版本。此验收版不增加运行依赖；正式服部署及 GitHub Release 由维护者另行决定。
