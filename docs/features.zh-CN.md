# 3dtabletop 当前功能清单

本清单对应当前代码中的 17 个游戏入口。自动测试和服务端探针结果见交付包中的验证记录；客户端画面、音效和帧率由实际联机验收。

## 游戏

| 类型 | 当前支持 |
| --- | --- |
| 棋盘 | 象棋、五子棋、国际象棋、中国跳棋、西洋跳棋、黑白棋、9／13／19 路围棋、四子棋 |
| 骰子 | Ludo、快艇骰子 |
| 卡牌 | Color Eight、斗地主、骗子酒馆扑克牌模式、德州扑克 |
| 麻将 | 日本、四川、广东、台湾房规 |

具体规则、人数和可选项见 [游戏模式](game-modes.zh-CN.md) 与 [麻将房规](mahjong.zh-CN.md)。已停用的游戏不出现在创建菜单中，也不恢复其旧规则存档。

## 房间与操作

- 创建、浏览、加入、准备、机器人、回合计时、观战、回到游戏、离开房间与再来一局。
- 每个桌面统一使用潜行＋右键打开菜单；游戏选择按钮按两列逐行排列。顶部资源包开关、返回游戏／浏览房间使用文字链接，后两者按玩家是否在房间中互斥显示。
- 日麻支持按住疾跑键（默认 Ctrl）固定看桌；理、和、鸣、切是玩家私有开关，瞄准时只显示功能说明，模型明暗区分状态。
- 规则动作、种子、座位、房间选项和桌子位置保存在 schema 1 存档中；支持重启恢复与历史回放。玩家悔棋功能已移除。
- 原生 Paper Dialog 提供设置和操作页；回调再次校验权限、房间身份和当前合法动作。
- `3dtabletop.use` 控制使用权限；命令包含 Tab 补全。

## 显示与音效

- 支持原版显示、CraftEngine 资源模型及按玩家切换的 mixed 模式。
- 原版扑克与 Color Eight 正面采用 32×48 头颅贴面，每张 24 个头颅；牌背使用白边和蓝背两个方块，私人正面只对所属玩家显示。
- 棋盘使用静态地图贴面，地图编号跨重启保留；动态棋子、骰子、指针与动画由显示实体生成。
- 快艇骰子使用相邻的计分桌与骰子桌；骰子可在排列区与保留区切换，瞄准骰子和计分格时有私人高亮。
- 原版音效覆盖落子、翻面、投骰、出牌、下注等事件；启用资源包的玩家使用对应采样。具体事件、来源与许可见 [游戏音效说明](sounds.zh-CN.md)。

## 配置与依赖

- 默认英文；玩家文字来自 `languages/` 下的语义键，语言文件支持热重载。
- 资源包配置只需 URL，摘要内置于对应插件 JAR；应使用同一交付中的 ZIP。
- CraftEngine 为可选模型依赖；原版显示和原生菜单不需要 Casino、AuthMe、Geyser、ServerGames 或 ServerMenu。
- 源码、注释和诊断使用英文；用户更新记录与验收说明使用中文。
