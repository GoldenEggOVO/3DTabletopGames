# 游戏模式与房间规则

[English](game-modes.md) | [简体中文](game-modes.zh-CN.md)

本文说明当前开发版本，尚未发布为 Release，也未部署正式服。现有游戏入口和操作见[当前功能清单](features.zh-CN.md)，客户端实测项目见[验收清单](acceptance.zh-CN.md)；构建与检查方法见[验证说明](verification.md)。

麻将手牌与公开牌采用一致的尺寸和朝向；本人瞄准时只抬起目标手牌，同类牌高亮只对本人可见。吃碰杠先选择动作再选择完整组合，立直只允许合法弃牌；日麻立直后自动出牌，在可以和牌时停下。宝牌使用五槽面板并显示供托／本场计数，和牌者的手牌全部平放。按住疾跑键（默认 Ctrl）进入固定看桌镜头，松开恢复；潜行＋右键打开桌面菜单。四川换三张、定缺与 Color Eight 跳过／选色均直接在桌面操作。

## 创建一局游戏

1. 输入 `/3dtabletop`，从游戏目录选择玩法。
2. 在游戏设置页选择**与好友游玩**或**与陪练游玩**，并调整支持的人数；麻将地区与围棋棋盘大小也在这里选择。
3. 需要修改默认规则时打开**详细规则**，点击规则项切换取值，设置较多时使用上一页、下一页。**返回**会保留所选规则并回到基础设置。
4. 好友模式选择**创建房间**，陪练模式选择**与陪练开局**。好友入座后准备；其他真人均准备后，房主也可补齐剩余陪练座位。

**规则在创建房间时锁定。** 后加入的玩家使用同一套规则，再来一局也保留这些规则。需要更换规则时创建新房间。命令 `/3dtabletop create <kind> [players]` 使用默认规则，自定义规则请使用游戏设置页。

等候页突出准备和补陪练开局；对局页回到实体桌面，不再显示完整手牌／棋盘动作选择入口。围棋停着、计分确认／继续保留为单独的合法状态按钮。离开房间直接显示在房间菜单中，玩家悔棋功能已移除。帮助／详情入口已移除。所有 Close 统一为底部出口、红字方括号和同一宽度；自定义模板中的 Close 也统一渲染，磁盘 YAML 不被覆盖。

| 游戏 | 人数 | 开局设置 |
| --- | --- | --- |
| 中国象棋 | 2 | 好友或陪练 |
| 国际象棋、西洋跳棋、黑白棋、四子棋 | 2 | 好友或陪练；房主先手、后手或随机 |

| Ludo 英国十字戏 | 2–4 | 首子出发、阻挡、到家要求、结束方式 |
| 中国跳棋 | 2、3、4、6 | 跳过己方棋子、进入其他营地、结束方式 |
| 彩八 | 2–5 | 第一位出完立即结束 |
| 麻将 | 4 | 四种地方玩法及各自房规 |
| 斗地主 | 3 | 叫分、地主与农民、完整牌型 |

### 先后手与房主身份

先后手设置决定谁坐在规则规定的开局席位：国际象棋仍由白方先走，五子棋和黑白棋仍由黑方先走。因此，选择后手或随机时，房主可能被移动到棋桌另一侧。房主身份仍属于创建者，补齐陪练等权限不会随先手席位转交给对手。随机先手在再来一局时重新选择，恢复同一局时保持原结果。

### 五子棋

棋盘保持 15×15。默认双方连成五子或更长即可获胜。三个限制分别只作用于黑方，白方仍可凭五子及长连获胜；禁着点不会出现在合法落点中。双三、双四按 [RIF 规则 9.2–9.3](https://gomoku.renju.net/rifrules/)中的棋形与合法延伸判断，不包含连珠比赛的开局交换流程。

### Ludo 英国十字戏

每人四枚棋子。六点可让一枚棋子从基地出发，并获得再次掷骰的机会。在公共跑道落到对手所在格会将其棋子送回基地。本模式没有连续三次六点处罚。

- **开局已在跑道上：**每局初始化时，各玩家仅第一枚棋子自动出发。自动出发只发生在开局；棋子被吃回基地后，仍须六点才能再次出发。
- **最多三次出发掷骰：**所有棋子从基地开始。在该玩家尚未让第一枚棋子出发前，每回合最多尝试三次掷出六点。首次出发后，即使棋子全部被吃回，也不会重新获得三次尝试资格。
- **掷出六点：**所有棋子从基地开始，每回合只有一次出发尝试。
- **阻挡：**单枚棋子就能阻止跨越，己方、对方均有效；回家通道的中间格也适用。起点与终点不参与阻挡判断，因此仍可落在有棋子的终点，包括在公共跑道落点吃子。
- **精确点数：**必须正好走完剩余距离才能到家。选择**允许超点**时，超出的步数直接按到家处理。
- **全部名次：**四枚棋子全部到家的玩家获得名次并退出轮转；仅剩一人时自动给出最后一名。即使靠六点完成全部棋子，已完成玩家也不会再掷一次。

出发选项参考了 [Switch 版 Ludo 实机攻略](https://gamefaqs.gamespot.com/switch/286602-clubhouse-games-51-worldwide-classics/faqs/78437/ludo)，[任天堂更新记录](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49554/p/989)也记载了出发阈值与重掷次数的修正。本插件的精确行为以上述条目为准，包括只在开局自动出发的约定。

### 中国跳棋

本模式保留 **121 孔六角星棋盘、每人十枚棋子及 2／3／4／6 人支持**。[Switch 版中国跳棋攻略](https://gamefaqs.gamespot.com/switch/286602-clubhouse-games-51-worldwide-classics/faqs/78437/chinese-checkers)描述的是三人、每人六子的较小棋盘；本插件参考其中的选项，继续使用现有的大棋盘。

- 禁止**跳过己方棋子**时，己方棋子不能作为跳跃桥子，仍可跳过对方棋子。
- 禁止**进入其他营地**时，多段跳的每个中途落点与最终落点都必须避开其他营地；自己的起点营和目标营允许进入。
- 棋子进入目标营后不能再离开目标营。
- **全部名次**会跳过已完成玩家的回合，其棋子仍留在棋盘上供其他玩家借跳；最后一位未完成者获得末位名次。重复局面、全员受阻等和局条件仍然有效。

## 彩八（Color Eight）：54 张牌玩法

规则依据官方 Blazing 8s 说明，以及本地记录的对局状态和客户端规则证据。牌面使用原创 B 版图案；红、黄、蓝、紫是本插件的配色。

- 支持 2–5 人，每人起手五张，第一席先行。开局翻一张有色牌，开局不触发特殊效果。
- 每色各一张 1、2、3、4、5、6、7、9、10、摸一、跳过、反转；另有四张彩8和两张交换牌，共 54 张。
- 匹配当前颜色或牌型；彩8和交换牌可在本人回合直接使用。两人时反转与跳过在效果和牌型匹配上等同。
- 彩8：点牌后在牌上方显示四个私有颜色按钮，选色后打出对应颜色底面的 8。
- 摸一：所有其他玩家各摸一张，不跳过、不叠加。
- 跳过：跳过下一位；反转：改变方向，两人时由自己继续。
- 交换：打出后，把剩余手牌与当前方向的下一位交换，保留之前的有效颜色和牌型，随后轮到下一位。
- 每回合可主动摸一次。摸后仍可出手中任意合法牌或跳过；摸后无合法牌自动过牌。直接点跳过会先摸一张再过牌。
- 人类回合固定 30 秒，摸牌或进入选色阶段不会刷新倒计时。超时自动摸牌过牌；已经选中彩8时，按剩余手牌最多的颜色自动选色。
- 先出完者立即获胜，最后一张的特殊效果不再执行，包括交换牌。没有报牌、漏报处罚和全部名次选项。
- 摸牌前如牌库为空，保留最上方弃牌并洗回其余弃牌。

彩八使用直径三格的圆桌。超多手牌保持单排重叠，瞄准时只抬起该牌，完整显示牌面。6 和 9 带下划线。本人的非法牌仅在本人回合呈灰色，其他回合正常显示。

## 当前卡牌存档

命令与存档标识为 `color-eight`，当前规则版本 2。保留当前格式的存档与语言文件，更新前先备份并验证，见 [升级说明](migration.zh-CN.md)。

## 麻将设置

四种玩法均为四人桌，使用对局积分。可选**日麻、广东、四川、台湾**。

| 通用设置 | 默认 | 可选值 |
| --- | --- | --- |
| 地方玩法 | 日麻 | 上述四种玩法 |
| 对局长度 | 广东单局，其余东风 | 单局／东风／东南半庄 |
| 初始点数 | 25,000 | 25,000／30,000／35,000 |

在基础设置选择玩法后，打开**详细规则**查看该地区的规则项。在尚未创建房间的设置草稿中切换地区，会重置地区专属设置；显式设定的对局长度和初始点数会保留。各地手牌数、计分、选项默认值、连庄与规则边界见[麻将玩法与选项表](mahjong.zh-CN.md)。

## 私有手牌与公开信息

彩八与麻将的暗手正面只向持有者显示。其他玩家与旁观者能看到牌背／张数、公开弃牌及明牌。直接点击桌面上的牌与动作按钮。彩八显示当前颜色、方向、剩余牌堆和顶张弃牌；麻将菜单显示每位玩家的对局积分。

两种游戏均使用原生方块拼出的原创牌面，无需资源包。麻将牌显示花色与字牌图案；彩八使用竖立牌。彩八瞄准一张牌只将它抬高；麻将只抬起选中牌。通过实体牌与桌面按钮选择合法动作。彩八入座玩家在允许摸牌时可右键中央牌堆；不允许的摸牌不会改变局面。实时新摸到的牌从牌堆移动到本人手中，初次显示、重连与存档恢复直接显示到位后的手牌。

其他棋桌也有显示调整：象棋棋面保留中文，包括“砲”；Ludo 小人不再显示浮动编号，叠子时仍可在菜单中区分具体棋子；骰台只保留骰子模型，移除额外的假影模型。

陪练定位为休闲对手。麻将陪练会完成换三张，避免反复取消选择；定缺选择自己最少的花色；有合法和牌、立直时优先采用；弃牌倾向保留对子与相连牌。策略只检查自己的手牌。

## 实体骰子侧台

新建 Ludo 房间会在主棋盘旁放置独立骰子侧台。创建时需为主桌和侧台留出空间。轮到自己时点击骰子或侧台掷骰，停稳后再行动。动画期间，实体点击、菜单／命令走棋、陪练行动暂不可执行，需在停稳后重试。显示点数来自房间规则状态，动画不会改变结果。

旧存档棋桌保留原世界坐标与紧凑骰台。恢复房间时直接显示已保存的静止结果，不重播过去的掷骰动画。骰台、卡牌与麻将牌均无需资源包。

## 存档兼容

- 房间文件继续使用 schema 1，保留房间 ID、座位、种子、动作历史和世界坐标；新记录另存所选规则、房主身份及骰台布局。
- 缺少规则选项字段的旧记录使用原默认值。Ludo 旧历史继续采用首子自动出发、不阻挡、精确到家、第一名结束。
- 恢复按已保存的选项重放。再来一局保留规则和房主，重新生成洗牌／骰子序列；选择随机先后手的游戏也重新抽取先手。
- 不认识的规则选项或不支持的规则版本会被拒绝恢复，避免静默改变旧局玩法。
- 已有语言和菜单自定义文件保留，缺少的文字使用内置英文回退。
- 自定义布局保留原顺序与样式，需要新版布局时先备份再手动合并模板。schema 1 及剩余四种麻将规则保持；已移除模式的旧存档按迁移说明明确拒绝恢复。

升级与旧房间导入见[迁移说明](migration.zh-CN.md)。[任天堂游戏目录](https://www.nintendo.com/jp/switch/as7ta/games/index.html)是收录范围的一手资料；本文引用的 GameFAQs 页面属于独立实机攻略，不是任天堂官方规则规范。本插件支持的玩法以这里说明的规则与可选值为准。

### 麻将桌面信息与视角

- 普通牌共四张：本人手牌 2 张／公开 0 张 → Remaining 2；本人 1 张／公开 1 张 → Remaining 2。牌河、副露、公开指示牌和响应牌按实体牌 ID 去重，赤五与普通五合并计算。这是未见张数，可能在别人手中或王牌中，不代表未来还能摸到几张；桌心数字才是规则引擎当前可摸牌墙数量。
- 最多 17 张手牌排成一行。组合预览与未见张数仅本人可见；点击旧组合时仍重新校验当前合法动作。
- 倒计时与真人／陪练／离线托管的实际时限一致，暂停时停止显示，不增加第二套计时或更改规则。
- 疾跑键（默认 Ctrl）视角要求已入座、有权限且在桌边。按住疾跑键时临时进入观察者模式，连接仅本人可见的固定镜头，锁定位置及朝向；自己与盔甲不进入镜头，期间只看桌，松开后恢复原游戏模式、位置、朝向、飞行、重力与隐身状态再打牌。保留上一版前移 1 格、下移 0.2 格后的眼睛位置，手牌和边框指示牌可能落在身后。菜单、离桌、死亡、外部传送及关闭恢复临时状态。其他插件取消游戏模式恢复时保留固定镜头并在同步时重试；异常断线／重启后通过保存记录恢复。外部游戏模式变更保留其指定模式。返回位置被堵或返回传送被取消时不强制传送。镜头、盔甲隐藏和 Shift＋右键的客户端触发需实机验收。立直棒长度由 0.12 增至 0.24 格，每根仍为两个实体。

### 牌面与桌边显示

麻将万字、风牌、发／中及花牌文字改用原生笔画模型。五个私人宝牌槽位嵌在四面木框正面中间，分别朝向各自座位，开杠时依次揭示，下面显示供托与本场计数；这只是同一批指示牌的四面显示，不增加牌墙中的牌。舍牌从靠桌心的一排开始，每排六张从左到右，再向本人方向换行。固定看桌视角已越过木框和本人立牌，允许其落在身后，松开疾跑键后查看。

日麻宝牌与赤五用原版附魔 ItemDisplay 流光覆盖原花纹：本人手牌仅本人可见，公开舍牌与副露均可见；开杠更新公开指示牌后同步刷新。指示牌本身不直接当作宝牌标记，暗牌及未公开的里宝牌不提前提示。本次仅增加显示，计分规则不变；宝牌增加番数，本身不算役。流光的客户端外观仍需实机验收。

彩八不可出的牌只降低亮度（15 → 7），保留原颜色与花纹；可出时恢复。指针悬停仅抬高 0.085 格，邻牌不移动。

彩八手牌按当前顺序从左到右平行斜叠，后一张稍微靠前，不再弧形展开。牌堆与弃牌回收都无法提供新牌时，有合法牌就必须出牌，不能摸牌或跳过；整手无合法牌才允许跳过，超时会代出合法牌。含有已经停用的非法空堆摸牌／跳过动作的历史会明确拒绝恢复。

原生模型实体数量见[模型数量报告](native-table-counts.zh-CN.md)。
