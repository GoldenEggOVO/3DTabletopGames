# 游戏模式与房间规则

[English](game-modes.md) | [简体中文](game-modes.zh-CN.md)

本文说明 **1.7.5-SNAPSHOT** 开发版本，尚未发布为 Release，也未部署正式服。本地图案与模型预览不能代替 Minecraft 客户端验收；构建证据与验收状态见[验证说明](verification.md)。

麻将桌面公开牌恢复为与手牌同宽的原生模型，桌心余牌数字再次放大。瞄准本人或公开牌时，同类型牌仅对本人高亮；只有直接瞄准的手牌抬起。新摸牌与旧手牌之间留空，摸牌不会挪动旧手牌；持续点击跨过其他玩家回合时，也会拦住原位置换来的另一张牌。不能弃出的牌呈灰色，完整日麻牌型没有役时，瞄准实际摸牌或正在响应的舍牌会显示红色 No Yaku。先点吃／碰／杠，再点完整组合；立直按钮进入选牌状态，只有合法立直弃牌可选；荣和与自摸各有按钮。日麻宝牌指示牌位于边框中间，副露留在本人右下角，風位挪到边角避免遮挡。Shift 视角降低并临时隐身，仍能看见自己的立牌正面，松开恢复。四川麻将换三张直接点选／取消手牌，再点确认；定缺使用桌面按钮。 Last Card 的旋转方向环和 6／9 下划线保持可用，现有 1–8 牌库不变。

## 创建一局游戏

1. 输入 `/3dtabletop`，从游戏目录选择玩法。
2. 在游戏设置页选择**与好友游玩**或**与陪练游玩**，并调整支持的人数；麻将地区与围棋棋盘大小也在这里选择。
3. 需要修改默认规则时打开**详细规则**，点击规则项切换取值，设置较多时使用上一页、下一页。**返回**会保留所选规则并回到基础设置。
4. 好友模式选择**创建房间**，陪练模式选择**与陪练开局**。好友入座后准备；其他真人均准备后，房主也可补齐剩余陪练座位。

**规则在创建房间时锁定。** 后加入的玩家使用同一套规则，悔棋和再来一局也保留这些规则。需要更换规则时创建新房间。命令 `/3dtabletop create <kind> [players]` 使用默认规则，自定义规则请使用游戏设置页。

等候页突出准备和补陪练开局；对局页回到实体桌面，不再显示完整手牌／棋盘动作选择入口。围棋停着、计分确认／继续及 Last Card 报牌保留为单独的合法状态按钮。只有确定棋盘游戏显示悔棋申请，退出仍可使用。帮助／详情入口已移除。所有 Close 统一为底部出口、红字方括号和同一宽度；自定义模板中的 Close 也统一渲染，磁盘 YAML 不被覆盖。

| 游戏 | 人数 | 开局设置 |
| --- | --- | --- |
| 中国象棋 | 2 | 好友或陪练 |
| 国际象棋、西洋跳棋、黑白棋、四子棋 | 2 | 好友或陪练；房主先手、后手或随机 |
| 五子棋 | 2 | 先后手；黑方双三、双四、长连限制 |
| 围棋 | 2 | 9×9、13×13、19×19 棋盘 |
| Ludo 英国十字戏 | 2–4 | 首子出发、阻挡、到家要求、结束方式 |
| 中国跳棋 | 2、3、4、6 | 跳过己方棋子、进入其他营地、结束方式 |
| Last Card | 2–4 | 第一名结束或排完全部名次 |
| 麻将 | 4 | 四种地方玩法及各自房规 |

Yacht 与飞行棋仍不开放创建新房间；受支持的历史房间记录仍可恢复。

### 先后手与房主身份

先后手设置决定谁坐在规则规定的开局席位：国际象棋仍由白方先走，五子棋和黑白棋仍由黑方先走。因此，选择后手或随机时，房主可能被移动到棋桌另一侧。房主身份仍属于创建者，补齐陪练等权限不会随先手席位转交给对手。随机先手在再来一局时重新选择，恢复同一局时保持原结果。

### 五子棋

棋盘保持 15×15。默认双方连成五子或更长即可获胜。三个限制分别只作用于黑方，白方仍可凭五子及长连获胜；禁着点不会出现在合法落点中。双三、双四按 [RIF 规则 9.2–9.3](https://gomoku.renju.net/rifrules/)中的棋形与合法延伸判断，不包含连珠比赛的开局交换流程。

### Ludo 英国十字戏

每人四枚棋子。六点可让一枚棋子从基地出发，并获得再次掷骰的机会。在公共跑道落到对手所在格会将其棋子送回基地。本模式没有连续三次六点处罚。

- **开局已在跑道上：**每局初始化时，各玩家仅第一枚棋子自动出发。自动出发只发生在开局；棋子被吃回基地后，仍须六点才能再次出发。
- **最多三次出发掷骰：**所有棋子从基地开始。在该玩家尚未让第一枚棋子出发前，每回合最多尝试三次掷出六点。首次出发后，即使棋子全部被吃回，也不会重新获得三次尝试资格。
- **掷出六点：**所有棋子从基地开始，每回合只有一次出发尝试。
- **阻挡：**单枚棋子就能阻止跨越，己方、对方均有效；回家通道的中间格也适用。起点与终点不参与阻挡判断，因此仍可落在有棋子的终点，包括在公共跑道落点吃子。
- **精确点数：**必须正好走完剩余距离才能到家。选择**允许超点**时，超出的步数直接按到家处理。
- **全部名次：**四枚棋子全部到家的玩家获得名次并退出轮转；仅剩一人时自动给出最后一名。即使靠六点完成全部棋子，已完成玩家也不会再掷一次。

出发选项参考了 [Switch 版 Ludo 实机攻略](https://gamefaqs.gamespot.com/switch/286602-clubhouse-games-51-worldwide-classics/faqs/78437/ludo)，[任天堂更新记录](https://en-americas-support.nintendo.com/app/answers/detail/a_id/49554/p/989)也记载了出发阈值与重掷次数的修正。本插件的精确行为以上述条目为准，包括只在开局自动出发的约定。

### 中国跳棋

本模式保留 **121 孔六角星棋盘、每人十枚棋子及 2／3／4／6 人支持**。[Switch 版中国跳棋攻略](https://gamefaqs.gamespot.com/switch/286602-clubhouse-games-51-worldwide-classics/faqs/78437/chinese-checkers)描述的是三人、每人六子的较小棋盘；本插件参考其中的选项，继续使用现有的大棋盘。

- 禁止**跳过己方棋子**时，己方棋子不能作为跳跃桥子，仍可跳过对方棋子。
- 禁止**进入其他营地**时，多段跳的每个中途落点与最终落点都必须避开其他营地；自己的起点营和目标营允许进入。
- 棋子进入目标营后不能再离开目标营。
- **全部名次**会跳过已完成玩家的回合，其棋子仍留在棋盘上供其他玩家借跳；最后一位未完成者获得末位名次。重复局面、全员受阻等和局条件仍然有效。

## Last Card：52 张牌玩法

Last Card 使用原创表现，不使用品牌牌面美术，其牌组和特殊牌效果与 UNO 有区别。玩法参考 [Last Card 实机攻略](https://gamefaqs.gamespot.com/switch/286602-clubhouse-games-51-worldwide-classics/faqs/78437/last-card)，以下是本插件实际实现的房间规则。

| 牌组 | 内容 |
| --- | --- |
| 红、黄、蓝、紫四种颜色 | 每色各一张 1–8、跳过、反转、摸二、摸三，共 12 张 |
| 万能变色牌 | 四张，打出时选择接下来的颜色 |
| 合计 | 52 张，每人起手五张 |

先手随机选出。开局弃牌堆为空，首位玩家可任选一张出牌。之后须匹配当前颜色、数字／符号，或打出万能变色牌；选择万能牌时同时指定颜色。

| 操作 | 效果 |
| --- | --- |
| 跳过 | 跳过下一位仍在对局中的玩家；两人时自己再行动 |
| 反转 | 改变轮转方向；两人时仍轮到对方 |
| 摸二／摸三 | 下一位可接同类罚牌，不限颜色，或承担累计罚摸；+2 与 +3 不能互接 |
| 摸牌 | 没有罚摸时，仅无牌可出才摸一张；摸牌即结束回合，不能立即打出刚摸到的牌 |
| 宣告 Last Card | 手中两张时，须在打出倒数第二张之前宣告；忘记则罚摸五张 |

存在罚摸时只能接同类罚牌，万能牌不能抵消罚摸。牌库耗尽后保留最上方弃牌，将之前的弃牌洗回牌库。

**第一名结束**在有人出完手牌时结束本局。**全部名次**让出完牌的玩家退出轮转，其最后一张牌适用的效果继续影响剩余玩家；只剩一位时确定最后名次。最先出完牌者仍为本局胜者。

## 麻将设置

四种玩法均为四人桌，使用对局积分。可选**日麻、广东、四川、台湾**。

| 通用设置 | 默认 | 可选值 |
| --- | --- | --- |
| 地方玩法 | 日麻 | 上述四种玩法 |
| 对局长度 | 广东单局，其余东风 | 单局／东风／东南半庄 |
| 初始点数 | 25,000 | 25,000／30,000／35,000 |

在基础设置选择玩法后，打开**详细规则**查看该地区的规则项。在尚未创建房间的设置草稿中切换地区，会重置地区专属设置；显式设定的对局长度和初始点数会保留。各地手牌数、计分、选项默认值、连庄与规则边界见[麻将玩法与选项表](mahjong.zh-CN.md)。

## 私有手牌与公开信息

Last Card 与麻将的暗手正面只向持有者显示。其他玩家与旁观者能看到牌背／张数、公开弃牌及明牌。直接点击桌面上的牌与动作按钮。Last Card 还显示当前颜色、方向、累计罚摸和顶张弃牌；麻将菜单显示每位玩家的对局积分。

两种游戏均使用原生方块拼出的原创牌面，无需资源包。麻将牌显示花色与字牌图案；Last Card 使用更大的竖立牌。Last Card 瞄准一张牌会将它抬高，并让邻牌稍微让位；麻将只抬起选中牌。通过实体牌与桌面按钮选择合法动作。Last Card 入座玩家在允许摸牌时可右键中央牌堆；不允许的摸牌不会改变局面。实时新摸到的牌从牌堆移动到本人手中，初次显示、重连与存档恢复直接显示到位后的手牌。

其他棋桌也有显示调整：象棋棋面保留中文，包括“砲”；Ludo 小人不再显示浮动编号，叠子时仍可在菜单中区分具体棋子；骰台只保留骰子模型，移除额外的假影模型。

陪练定位为休闲对手。麻将陪练会完成换三张，避免反复取消选择；定缺选择自己最少的花色；有合法和牌、立直时优先采用；弃牌倾向保留对子与相连牌。策略只检查自己的手牌。

## 实体骰子侧台

新建 Ludo 房间会在主棋盘旁放置独立骰子侧台。创建时需为主桌和侧台留出空间。轮到自己时点击骰子或侧台掷骰，停稳后再行动。动画期间，实体点击、菜单／命令走棋、陪练行动及新的悔棋申请暂不可执行，需在停稳后重试。显示点数来自房间规则状态，动画不会改变结果。

旧存档棋桌保留原世界坐标与紧凑骰台。恢复房间时直接显示已保存的静止结果，不重播过去的掷骰动画。骰台、卡牌与麻将牌均无需资源包。

## 存档兼容

- 房间文件继续使用 schema 1，保留房间 ID、座位、种子、动作历史和世界坐标；新记录另存所选规则、房主身份及骰台布局。
- 缺少规则选项字段的旧记录使用原默认值。Ludo 旧历史继续采用首子自动出发、不阻挡、精确到家、第一名结束。
- 恢复与悔棋按已保存的选项重放。再来一局保留规则和房主，重新生成洗牌／骰子序列；选择随机先后手的游戏也重新抽取先手。
- 不认识的规则选项或不支持的规则版本会被拒绝恢复，避免静默改变旧局玩法。
- 已有语言和菜单自定义文件保留，缺少的文字使用内置英文回退。
- 原样保留的 1.7.0 默认设置、房间与手牌模板通过内容匹配后，仅在内存中采用新版布局，不改磁盘文件字节。自定义布局保留原顺序与样式，需要新版布局时先备份再手动合并模板。schema 1 及剩余四种麻将规则保持；已移除模式的旧存档按迁移说明明确拒绝恢复。

升级与旧房间导入见[迁移说明](migration.zh-CN.md)。[任天堂游戏目录](https://www.nintendo.com/jp/switch/as7ta/games/index.html)是收录范围的一手资料；本文引用的 GameFAQs 页面属于独立实机攻略，不是任天堂官方规则规范。本插件支持的玩法以这里说明的规则与可选值为准。

### 麻将桌面信息与视角

- 普通牌共四张：本人手牌 2 张／公开 0 张 → Remaining 2；本人 1 张／公开 1 张 → Remaining 2。牌河、副露、公开指示牌和响应牌按实体牌 ID 去重，赤五与普通五合并计算。这是未见张数，可能在别人手中或王牌中，不代表未来还能摸到几张；桌心数字才是规则引擎当前可摸牌墙数量。
- 最多 17 张手牌排成一行。组合预览与未见张数仅本人可见；点击旧组合时仍重新校验当前合法动作。
- 倒计时与真人／陪练／离线托管的实际时限一致，暂停及悔棋协商时暂停显示，不增加第二套计时或更改规则。
- Shift 视角要求已入座、有权限且在桌边；固定位置但允许鼠标转动。松开恢复进入前的位置、朝向、重力及原隐身状态。菜单、离桌、死亡、外部传送及关闭会清理临时状态。返回位置被堵或其他插件取消返回传送时，退出固定视角并恢复原重力，不强制传送；需在隔离服验收镜头手感及反作弊兼容。
