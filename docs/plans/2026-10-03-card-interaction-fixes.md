# 桌面交互与原版卡牌修复

用户已要求修复 Raise、整桌潜行菜单和原版重叠闪烁，并确认原版卡牌采用约五个实体的完整像素贴面。

## 实施范围

1. 修正德州加注输入框名称，并在真实 Paper 环境验证弹窗创建与非当前玩家限制。
2. 让入座玩家与未入座玩家共用完整桌面命中几何。覆盖棋盘边缘、四子棋架、飞行棋侧骰盘和快艇骰子双桌；保留距离、墙体遮挡、潜行与右键限制。
3. 以 Casino 的现有本地图案为输入生成原版文字像素贴面。每张标准扑克牌一个牌体和四个像素面，保持尺寸、朝向、隐私、悬停与选择行为。
4. 修复已确认的原版图案和桌面共面重叠；保留已验收的圆桌轮廓与实体数量。
5. 验证后打包 1.10.4-SNAPSHOT，同步源码到现有 GitHub 分支并备份更新独立测试服。暂不发布 Release。

## 实现约束

- 原版地图在客户端固定为一格，无法保持现有小牌尺寸和任意座位朝向，因此采用用户进一步确认的原版文字像素贴面。
- 不改变玩法、存档、其他插件和资源包；玩家文字仍只放在 languages。
- 私有手牌实体只展示给所属玩家；仅开启资源包的附近玩家使用现有单模型牌。
- 测试先复现失败，再核对修复；运行时验证和客户端视觉验收分别报告。

## 验收

- Raise 创建实际输入弹窗，输入键符合服务端规则。
- 空桌面潜行右键能开菜单，重复事件只开一次；隔墙、超距和桌间空隙不命中。
- 标准原版扑克牌不超过五个实体，图案语义、尺寸和私有可见性保持一致。
- 共面重叠回归、全部 Java 测试、资源包检查与独立启动验证通过。
- 部署前核对测试服 UUID 与端口，部署后核对 JAR、启动、资源包摘要和受保护文件。
