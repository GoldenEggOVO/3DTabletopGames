# 资源包模型优化（1.10.9）

## 改动

圆桌、圆角棋盘、棋子、筹码和圆角卡牌改用封闭外壳。顶底各用一个带轮廓遮罩的面，侧面只沿外轮廓排列；四子棋另外保留 42 个孔的内壁。删除实心区域内部的薄块隔板。

圆桌使用 48 段外轮廓，最大半径偏差约 0.0033 方块。保留原有桌布、牌面图案、尺寸、模型 ID 和操作位置。原版模型与游戏规则沿用 1.10.8。

## 贴图与接缝

同源贴图、同归一化轮廓共享遮罩；模型不再引用未使用的源纹理。孔洞遮罩边界保守覆盖相邻像素，避免透明像素越过精确孔壁。

实际引用纹理从 31,431,366 增至 36,752,070 像素（约 17%）。这是资产像素统计，不是客户端显存实测。测试限制总量低于 40,000,000 像素，防止模型优化同时大幅放大贴图。

## 验证范围

234 个模型通过已安装 Minecraft 26.2 客户端的实际模型解析器。几何检查验证轮廓边接合、侧壁方向、立牌旋转和缩放后的顶点；资产检查验证孔洞、牌背、纹理引用和像素预算。

本地预览使用导出的实际模型与纹理，未模拟客户端光照。自动检查与服务端验证不能替代客户端画面、接缝、光照和 FPS 验收；面数下降不代表 FPS 按相同比例提升。
