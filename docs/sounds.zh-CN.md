# 游戏音效（1.10.14）

声音仅在服务端确认操作成功时触发。非法动作、显示刷新与重启回放保持静音；不会按模型数量或旁观人数重复播放。

## 卡牌游戏

Color Eight、斗地主、骗子酒馆与德州扑克共用 `tabletop3d:cards.play` 出牌音效，来自本次提供的 `oxidvideos-taking-playing-card-522520.mp3`。资源包内保存单声道 OGG，时长约 0.624 秒，稍微降低峰值避免破音。

一次出牌操作播放一次卡牌声，不会因同时打出多张牌而叠加。斗地主保留原版叫抢地主、不出／要不起及不同牌型的辅助效果；骗子酒馆删除原资源包质疑与实弹声，改用原版铃音、扳机点击或爆炸反馈，并保留轮盘等待间隔。德州扑克保留原有操作与筹码反馈。

自定义音效需要客户端启用桌游资源包；未启用时自动使用原版翻书声。两类玩家混合在桌旁时，各自只听对应的一份声音。资源包不会覆盖 Minecraft 自带的声音事件。

## 麻将与其他桌游

四种麻将规则共用九项资源包声音：选牌、倒计时、弃牌、摸牌、鸣牌、杠、立直、宝牌与和牌；未启用资源包时使用相应原版声音。棋类和快艇骰子使用原版声音。

全包现在有十项声音事件：九项麻将加一项共享卡牌声。斗地主和骗子酒馆均没有独立资源包声音目录。

## 配置

```yaml
sounds:
  enabled: true
  volume: 1.0
```

`volume` 为预设音量倍数，范围 0–1；`enabled: false` 或 `volume: 0` 关闭所有插件反馈。客户端可通过“方块”声音类别调整音量。回合提醒、选牌与倒计时只向对应玩家播放；出牌等操作声可由附近玩家听到。

## 验证范围

自动测试验证事件分类、混合模式分流、恢复静音、音量控制、资源包注册与 OGG 内容。服务端探针验证声音接口与原版事件注册。客户端实际响度、听感和动画同步仍需游戏内验收。
