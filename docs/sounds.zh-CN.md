# 游戏音效（1.10.15）

声音仅在服务端确认操作成功时触发。非法动作、显示刷新与重启回放保持静音；不会按模型数量或旁观人数重复播放。

## 卡牌游戏

Color Eight、斗地主、骗子酒馆与德州扑克共用 `tabletop3d:cards.play` 出牌音效，来自本次提供的 `oxidvideos-taking-playing-card-522520.mp3`。资源包内保存单声道 OGG，时长约 0.624 秒，稍微降低峰值避免破音。

一次出牌操作播放一次卡牌声，不会因同时打出多张牌而叠加。斗地主保留原版叫抢地主、不出／要不起及不同牌型的辅助效果；骗子酒馆删除原资源包质疑与实弹声，改用原版铃音、扳机点击或爆炸反馈，并保留轮盘等待间隔。德州扑克下注增加真实筹码堆叠声；出牌录音保持不变。

自定义音效需要客户端启用桌游资源包；未启用时自动使用原版翻书声。两类玩家混合在桌旁时，各自只听对应的一份声音。资源包不会覆盖 Minecraft 自带的声音事件。

## 麻将与其他桌游

四种麻将规则共用九项资源包声音：选牌、倒计时、弃牌、摸牌、鸣牌、杠、立直、宝牌与和牌；未启用资源包时使用相应原版声音。麻将原有九项录音保持不变。棋类、骰子与通用操作新增 Kenney CC0 素材；未启用资源包的玩家继续使用原版声音。

全包现在有 27 项声音事件：九项麻将、一项共享出牌声，以及十七项新增素材事件。斗地主和骗子酒馆均没有独立资源包声音目录；质疑和轮盘反馈保持原版声音。

## 新增素材与对应操作

| 操作 | 素材与声音事件 |
| --- | --- |
| 象棋、国际象棋等木质棋子落子 | 木质轻碰撞，`board.wood` |
| 围棋、五子棋落子 | 短促硬质碰撞，`board.stone` |
| 四子棋落子、黑白棋翻转、吃子 | `board.drop`、`board.flip`、`board.capture` |
| 快艇骰子掷骰、Ludo 单骰 | `dice.roll`、`dice.single` |
| 保留或取消保留骰子 | 拿起骰子的声音，`dice.hold` |
| Color Eight 摸牌 | 卡牌滑动，`cards.draw` |
| 德州扑克下注 | 筹码堆叠，`chips.bet` |
| 选择、跳过、确认、开始、胜利、平局、棋子到家 | 七项短界面提示，`table.*` |

骰子、筹码和部分落子使用随机变体，一次事件只选一个样本，不会将变体叠加播放。新素材统一转为单声道，并适当降低峰值；声音时长和动作触发节奏保留。

素材来自 [Kenney Casino Audio](https://kenney.nl/assets/casino-audio)、[Interface Sounds](https://kenney.nl/assets/interface-sounds)、[Impact Sounds](https://kenney.nl/assets/impact-sounds)，均为 CC0 1.0，可用于商业项目。原始许可文件保存在 `audio-source/kenney`，也随资源包放入 `licenses` 目录。事件与原始文件的对应关系见 `audio-source/kenney/events.json`。

## 配置

```yaml
sounds:
  enabled: true
  volume: 1.0
```

`volume` 为预设音量倍数，范围 0–1；`enabled: false` 或 `volume: 0` 关闭所有插件反馈。客户端可通过“方块”声音类别调整音量。选牌与倒计时只向对应玩家播放；出牌等操作声可由附近玩家听到。

## 验证范围

自动测试验证事件分类、混合模式分流、恢复静音、音量控制、资源包注册与 OGG 内容。服务端探针验证声音接口与原版事件注册。客户端实际响度、听感和动画同步仍需游戏内验收。
