# 游戏音效

1.6.1-SNAPSHOT 为全部 11 种可创建游戏和旧飞行棋房间增加 Minecraft 原生音效，无需资源包。

## 声音与事件

| 游戏或事件 | 听觉反馈 |
| --- | --- |
| 国际象棋、西洋跳棋 | 短木质落子声 |
| 中国象棋 | 较低的竹木敲击声 |
| 五子棋、9／13／19 路围棋 | 清脆石子敲击声 |
| 中国跳棋 | 短木琴音，提示完成跳步 |
| 黑白棋 | 短翻子声，一次操作只响一次，不按翻子数量叠加 |
| 四子棋 | 短空心落子声 |
| Ludo、旧飞行棋 | 小棋子点击、短摇骰声、棋子到家提示 |
| 吃子或提子 | 较有力度的木质声；包含吃过路兵和将对方叠子送回营地 |
| 围棋停手、标死、确认／恢复行棋 | 低音、轻点击、确认提示 |
| 开局、胜利／和局、完成悔棋 | 各有短提示 |
| 到你回合 | 仅对同世界、距桌面八格内且有操作权限的当前真人玩家播放 |

声音在服务端确认操作成功时触发。真人、菜单和机器人走棋共用同一条路径；不会按棋子实体数或观众数重复播放。落子与本局结束可能各播放一个提示。声音不等待客户端动画完成，实际听觉与显示延迟需客户端验收。

瞄准、刷新棋盘、重复菜单回调、非法动作和重启回放都不会播放落子声。悔棋只在完成后播放撤销提示，不重播被恢复的最后一步。没有循环音效或背景音乐。

## 配置

在 `plugins/3dtabletop/config.yml` 添加或调整：

```yaml
sounds:
  enabled: true
  volume: 1.0
```

`volume` 是原本轻音量预设的倍数，范围 0–1，建议先试默认或 0.5。`enabled: false` 或 `volume: 0` 关闭包括选子、私人轮次提示在内的全部插件声音。超出范围的数值限制在 0–1，非有限数值按静音处理。修改后重启服务器。

旧配置文件不会被覆盖，缺少这些字段时使用上述默认值。客户端可通过“方块”声音类别调节。附近玩家能听到棋桌发出的操作声；只有轮次与选子提示是私人声音。

## 验证范围

自动测试检查动作分类、捕获判定、重复抑制、恢复静音、配置边界和私人轮次提示。独立 Purpur 探针检查全部原生声音在服务器注册表中存在，并调用播放接口。

服务端检查不能证明客户端实际播放效果。请在 Minecraft 中确认不同游戏的声音、响度、多人桌旁的混音，以及音效与动画的主观协调性。
