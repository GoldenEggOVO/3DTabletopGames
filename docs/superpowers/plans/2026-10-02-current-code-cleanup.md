# 当前桌游代码清理计划

> 执行方式：在现有隔离工作树内使用 executing-plans，按功能删除并验证。

**目标：** 仅保留当前17个游戏入口及其规则、渲染、菜单、房间保存与验证工具，移除失效实现和旧版本适配。

**基线：** b7b8783651a15cda60aa884ec946639ee57f2210，1.10.0-SNAPSHOT。沿用 Java 25、Paper 26.2、CraftEngine 可选桥接、三种显示模式与现有资源包。

## 约束与判定

- 用户已授权清理旧版实现；不再恢复停用的 Aeroplane 房间，也不把它转换成 Ludo。
- 当前房间 schema、rulesVersion、身份、座位、种子、历史与锚点保持；非法事件必须在实时与回放中一致拒绝。
- 保留独立 RoomReplayVerifier：它是当前存档检查工具，有实际命令行调用，不能因没有插件入口引用就删除。
- 保留自定义菜单、语言格式与样式、资源包选择、权限校验及原子保存。
- 不按关键词删除：MessageText 的颜色代码解析用于当前语言与菜单；象棋规则引擎的内部回滚用于算法，不是玩家悔棋菜单。
- 不修改 Casino、其他服务器、既有备份或历史验证记录。用户更新说明使用中文。
- 普通源码同步 GitHub，备份后更新独立测试服；不创建 Release 或标签。
